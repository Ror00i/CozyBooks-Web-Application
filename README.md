# CozyBooks – Bookstore Web Application

## Project Overview
CozyBooks is a bookstore web application developed as part of a university course. The project focuses on creating a user-friendly website for browsing books and submitting purchase orders.

## Tools & Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Key Features
- Display books with their details and prices.
- Browse different pages of the bookstore.
- Submit book purchase orders.
- Store customer orders in an SQLite database.
- View submitted orders through an admin page.

## Project Structure
- `app.py` – Flask application and backend logic.
- `templates/` – HTML pages.
- `static/` – CSS, JavaScript, and images.
- `database.db` – SQLite database used by the application.
